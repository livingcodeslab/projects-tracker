* Integrations

** Explore Setting up Protocol via HTTP API

We begin by attempting to upload the previously defined labware onto the robot:
success.

With the labware thus uploaded, we can begin exploring the HTTP API.

#+begin_src shell
  curl http://OT2CEP20221010R03:31950/networking/status
#+end_src

#+RESULTS:
| {"message":"header.opentrons-version: Field required" | errorCode:"4000"} |

We get an error response; that's promising. At least we are receiving a response,
rather than a HTTP error.

Now, provide the header:

#+begin_src shell
  curl --header "opentrons-version: 2.28" http://OT2CEP20221010R03:31950/networking/status
#+end_src

#+RESULTS:
| {"message":"header.opentrons-version.literal['*']: Input should be '*'; header.opentrons-version.int: Input should be a valid integer | unable to parse string as an integer" | errorCode:"4000"} |

Ahh, an integer, okay. Try that:

#+begin_src shell
  curl --header "opentrons-version: 2" http://OT2CEP20221010R03:31950/networking/status
#+end_src

#+RESULTS:
| {"status":"full" | interfaces:{"wlan0":{"ipAddress":"172.x.x.x/21"     | macAddress:"B8:XX:XX:XX:XX:XX" | gatewayAddress:"172.x.x.x"    | state:"connected" | type:"wifi"} | eth0:{"ipAddress":null | macAddress:"B8:XX:XX:XX:XX:XX" | gatewayAddress:"" | state:"unavailable" | type:"ethernet"}}} |

Sweet! We get the networking information just fine (actual addresses obfuscated).

We have established that it is possible to interact with the robot over the HTTP
protocol, albeit to fetch information about the robot.

Now, let us try something more substantial — let us blink the lights!

#+begin_src shell
  curl --header "Content-Type: application/json" --header "opentrons-version: 2" http://OT2CEP20221010R03:31950/identify?seconds=10
#+end_src

#+RESULTS:
| {"message":"Method Not Allowed" | errorCode:"4000"} |

Oh, wrong method...  Ahh, should be POST. Try again:

#+begin_src shell
  curl --header "Content-Type: application/json" --header "opentrons-version: 2" -X POST http://OT2CEP20221010R03:31950/identify?seconds=10
#+end_src

#+RESULTS:
: {"message":"identifying"}

Nice! The  power-button light (gantry lights?) blinks for 10 seconds.

Now, let us home the robot...

#+begin_src shell
  curl --header "Content-Type: application/json" --header "opentrons-version: 2" -X POST http://OT2CEP20221010R03:31950/robot/home -d '{"target": "robot"}'
#+end_src

#+RESULTS:
: {"message":"Homing robot."}

We observe the robot's axes moving to the home edge.

One last, minor test - let us turn the rail lights on …

#+begin_src shell

#+end_src

#+RESULTS:
: {"on":true}

… and off

#+begin_src shell
