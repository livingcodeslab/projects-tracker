* Integration

We begin the day with processing the data from 2026-11-10, and analysing the
results.

The readings were taken in 3 rounds per chip, with each round cycling through
the reagents, from water, to 0.0005X PBS and 0.001X PBS, for a total of 18
expected results.

** Data Processing

Define relevant environment variables

#+begin_src shell :tangle 20261110envvars.env

  GDNASYNTH_REPO="${HOME}/livingcodeslab/guided-dna-synthesis-project/experiments/gfet-microfluidics-experiments"
  PYTHONPATH="${GDNASYNTH_REPO}${PYTHONPATH:+:}${PYTHONPATH}"

  # file variables
  DATE="20261110"
  RANDSTR="91mvtg"
  CHIPS=( "1" "2" )

then process the files:

- separate positive Drain-Source voltage readings from negative Drain-Source voltage readings
- use positive Drain-Source voltages readings to generate plots

#+begin_src shell :tangle 20261110-process-files.sh
  #!/bin/bash
  source "$(pwd)/20261110envvars.env"

  for chip in "${CHIPS[@]}";
  do
      for reading in "${READINGS[@]}";
      do
          for rkey in "${!REAGENTS[@]}";
          do
              python3 "${GDNASYNTH_REPO}/isswisafre.py" process-data \
                      "$(pwd)/static/${DATE}-chip-${chip}-${rkey}-reading${reading}-${RANDSTR}.csv" \
                      "$(pwd)/static/" &&
                  gnuplot << EOF && sed -i 's/replaceAll("]]>", "")/replaceAll("]]\\>", "")/g' "./static/${DATE}-chip-${chip}-${rkey}-reading${reading}-${RANDSTR}.svg"
  load "./20260220-plotting-styles.gp"

  set output "./static/${DATE}-chip-${chip}-${rkey}-reading${reading}-${RANDSTR}.svg"

  set title "Sweep in ${REAGENTS[$rkey]} Environment on OT-2R Robot with Orchestration (chip ${chip} -- many channels)"
  set xlabel "Gate Voltage (V)"
  set ylabel "Drain Current (A)"
  set datafile separator ","
  plot \
      "./static/${DATE}-chip-${chip}-${rkey}-reading${reading}-${RANDSTR}-positive.csv" \
      using "measured_gate_voltage":"drain_current" \
      title "${REAGENTS[$rkey]} Characteristics" \
      with lines
  EOF
          done
      done
  done
#+end_src

** Chip Identification

We could use "Drain-Source continuity" tests on the GFETs on a chip to uniquely
fingerprint chips by looking at the pattern/sequence of working and broken GFETs.

Some things to look out for:

- use a *binary open/short threshold* e.g.
  - intact channel: < (50 to 100)kΩ
  - torn/missing graphene > 10MΩ
- keep voltages low (recommendation -10mv to 10mv) for the fingerprinting
  sweep(s)
- set the *current compliance* limit on SMU (typically 10µA to 100µA) to
  instantly cap power if any GFET is shorted (hmm, this  add's a dimension to
  the fingerprinting (working, broken/open, shorted)
- with check for shorting, we can do a *ternary* threshold rather that *binary*,
  e.g. (treating gaps as open-circuit)
  - shorted; < 50Ω
  - gap: >50Ω to <300Ω
  - intact: 300Ω to 50kΩ
  - gap: >100kΩ to <10MΩ
  - open: > 10MΩ


** Multiplexing

To save on components, the selection of the active chip and the active channel
on the selected chip will need to be independent.

This way, the selection of the chip connects power to said chip (disconnecting
power from all others), ensuring that even though all the chips share the same
channel conductors, the channel selection applies only to the selected chip,
since it's the only chip where both the positive VCC and negative/ground are
connected. All others wil have those terminals open-circuit.

*Hard Requirement*: Allow selection of only one chip at a time.

The channels are a little different, you can select one channel, a number of
them, or all channels. The circuit design here will be interesting, to say the
least.

There are a number of issues with this, among them leakage currents and
parasitic capacitances, to take care of.

Look up:
- solid-state analog multiplexer ICs
- dual-supply CMOS analog multiplexers, e.g.
  - ADG1606
  - ADG732
  - ADG1404
  - TMUX1104
  - ADG1609
